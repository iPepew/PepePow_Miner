## Основа и включение наработок

Ветка создана от release/v1.0.5, SHA 46e76ac30d23fb40cd3b3a8fa4da01b71a2069b3, чтобы исправить обнаруженную пользователем ошибку HiveOS.
Это предварительная основа интеграции, а не выбор проверенного стабильного CUDA-бинарника.
Исторический v1.0.4 был собран из aee110519524ce4cbb4daa5f5e11d1be96ad5d91.
Тег v1.0.0 уже существует: новый выпуск не должен молча перемещать существующий тег. Предлагаемый отдельный тег: pepew-miner-1.0.

Свежий STATUS Lab содержит два кандидата e5a038e и 9895bf3, ожидающих аппаратных проверок. Они не включены автоматически.
Показатель 3–3.5 MH/s для RTX 3080/3080 Ti пока не связан с проверенным exact package и логом принятых шар.
Скриншот пользователя показывает RTX 3080 Ti и PepeW Miner v1.0.5, но запуск заканчивается ошибкой upstream URL до майнинга.

## До публикации

1. Зафиксировать выбранные исходники и поддерживаемое оборудование; проверить совместимость с текущим consensus PEPEPOW.
2. Собрать Linux/HiveOS пакет в доступной CUDA-среде, с timeout и абсолютным дедлайном.
3. Зафиксировать source SHA, toolkit, architectures, SHA256 архива и бинарника.
4. Проверить CPU и GPU correctness exact пакета; отдельно проверить установку HiveOS, принятые/отклонённые шары и статистику.
5. Опубликовать готовый пакет, checksums, инструкцию и только подтверждённые характеристики.
6. После проверки нового выпуска удалить прежние релизы, по поручению пользователя, сохранив необходимые recovery/evidence assets и исходную git-историю.

Текущая среда: git и g++ доступны; cmake, nvcc и gh не найдены.
Доступные GitHub-инструменты позволяют читать репозиторий и изменять файлы/ветки, но не предоставляют release create/delete/upload или workflow dispatch.
GPU задания, пул и production не запускались/не изменялись.
docs/public-1.0-release-inventory.json содержит 143 релиза. Это инвентаризация метаданных, НЕ резервная копия бинарников. Удаления не выполнены.

## Текст анонса — применять только после публикации

Представляем Pepew_Miner 1.0 — первый официальный публичный выпуск нашего майнера для PEPEPOW.

В этой версии мы объединили проверенные наработки проекта и подготовили единый пакет для установки. Исходный код, инструкция, список поддерживаемого оборудования и контрольные суммы опубликованы вместе с выпуском.

Это начало публичной линейки Pepew_Miner. Приглашаем сообщество тестировать майнер и делиться результатами: модель видеокарты, версия драйвера, настройки, хешрейт и статистика принятых и отклонённых шар помогут нам улучшать следующие версии.

Не утверждать «первый майнер для монеты вообще»: такое первенство не установлено.
