# PepeW Miner v0.6.0-PR

## Status

This is a prerelease for HiveOS and NVIDIA CUDA systems. It has been built and validated on an NVIDIA GeForce RTX 3080 (`sm_86`).

The 2 MH/s objective has **not** been reached in this build. It remains the next optimization target.

## Main result

The v0.6.0-PR autotuner tested 10 consensus-valid CUDA profiles and selected:

```text
profile=best-t64-b2
state_mode=3
threads=64
min_blocks=2
registers=96
spills=0 bytes
```

Measured RTX 3080 results:

```text
Internal benchmark: 1.732324 MH/s
Baseline benchmark: 1.631831 MH/s
Benchmark uplift:   +6.16%
Live pool average:  approximately 1.70 MH/s
Observed live range: 1.690-1.709 MH/s
```

## Validation

The selected package passed:

- core tests;
- CUDA tests;
- canonical header80 CPU/CUDA comparison;
- 32,768 critical-path CPU/CUDA samples;
- five HooHash consensus vectors;
- three benchmark runs for every tested profile;
- HiveOS installation and startup;
- pool connection, subscription and authorization;
- live accepted-share testing.

Validated pool sample:

```text
Accepted shares: 37
Rejected shares: 0
CUDA errors:     0
NVIDIA NVRM Xid: 0
```

The unrelated `XID 541` line observed in the system log came from the RTL8168/8111 network adapter, not the NVIDIA driver.

## Visible autotune progress

The HiveOS autotuner runs exactly 10 profiles and prints the current profile number and stage:

```text
[PROFILE 02/10] exact-defensive-state2
Status: BUILDING
```

A separate progress viewer is included at:

```text
tools/watch-v060-progress.sh
```

## Release gate

A claim of more than 2 MH/s is permitted only when both conditions are true:

```text
TARGET_2MH=PASS
sustained live pool hashrate > 2.000 MH/s
```

For v0.6.0-PR the recorded state is:

```text
TARGET_2MH=PENDING
```
