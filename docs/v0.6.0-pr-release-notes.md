# PepeW Miner v0.6.0-PR

## Purpose

This prerelease targets the serial HooHash V110 dependency executed after every matrix cell:

```text
sum -> fraction(sum / 1024) -> compare with 0.02 -> next cell
```

The previous v0.5.6 cold-path and occupancy experiments did not produce a material gain on RTX 3080. v0.6.0-PR therefore tests exact state-predicate representations while preserving consensus behavior.

## RTX 3080 autotune

The HiveOS autotuner runs exactly 10 visible profiles. Every profile is printed as:

```text
[PROFILE 02/10] exact-defensive-state2
Status      : BUILDING
```

Each profile must pass:

1. core tests;
2. CUDA tests;
3. 32,768 CPU/CUDA header80 samples;
4. canonical header80 vectors;
5. five consensus HooHash vectors;
6. three benchmark runs by default.

The first four profiles compare state representations. The remaining six sweep launch geometry for the fastest consensus-valid representation.

## Release gates

The package may be published as a GitHub prerelease after all of the following are recorded:

- all selected-profile tests pass;
- the archive and SHA256 are generated;
- the package starts on HiveOS;
- the pool connects and authorizes;
- accepted shares increase;
- no miner-caused rejected shares are observed during the validation window;
- the measured live hashrate is stated exactly as observed.

A claim of more than 2 MH/s is permitted only when both conditions are true:

```text
TARGET_2MH=PASS
sustained live pool hashrate > 2.000 MH/s
```

Until then, the release notes must describe 2 MH/s as an optimization target, not an achieved result.
