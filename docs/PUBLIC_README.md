# PepeW Miner — подготовка публичной версии 1.0

**Это кандидат публичной версии, ещё не стабильный релиз.** Общий бинарник
из source `2292825ea66a577a13e61ad63695b890396bf38b` проверен 19 октября 2026
на RTX 3080: Header80 и 5 consensus-векторов, 100 000 CPU/GPU сравнений без
расхождений, 120 секунд на текущем пуле — 22 принятые шары, 0 отклонённых.
Остановка оболочки и восстановление основного майнера подтверждены.
Это короткая проверка одного пула и одной карты, не длительный тест стабильности.

Статистика HiveOS в этом запуске: 2,202–2,255 MH/s. Сравнение с подтверждённой
базой в одинаковых условиях не проводилось; прирост скорости не заявлен.
Оптимизированный V100-профиль сохранён без изменений и аппаратно не проверен.
Исправление fixed-diff1 внесено только в общий профиль; поведение V100 на
текущем пуле не подтверждено. Нельзя представлять оба профиля как готовый stable.

Build: GitHub Actions 39208192790; аппаратная проверка: PepePow_Lab run39242460053.
Точные хеши и ограничения: results/release/fixed-share-target-20261019.json
в ветке release/1.0-fixed-share-target. CUDA unit-test в Release использует
отключённые assert и считается только smoke; доказательства корректности —
явные проверки consensus и differential.

## Что входит

| Профиль | Назначение | Особенность |
|---|---|---|
| general | Общая сборка, включая RTX | Встроены sm_61/70/75/80/86/89/120; наличие кода не равно аппаратной проверке |
| v100 | Оптимизированная Tesla V100 | sm_70, hotrun8, фиксированные 128 потоков |

Оба профиля включены в один архив. Оболочка HiveOS выбирает V100-профиль только
для устройства с именем V100 и архитектурой sm_70. Каждая карта запускается
отдельным процессом с CUDA_VISIBLE_DEVICES, заданным её UUID. На смешанном риге
используйте автоматическое число потоков: общее значение 512 не подходит V100.

Бинарники не пересобраны ради изменения внешнего номера версии. Их собственные
строки версии могут содержать прежнее имя/номер. `./pepepowminer --version`
показывает версию пакета; `./pepepowminer --backend-version` — исходного общего
бинарника. Для V100 добавьте `PEPEW_BINARY_PROFILE=v100`. Точные SHA исходников
и SHA256 всех исполняемых файлов приведены в BUILD_MANIFEST.json.

Измеренные требования двух miner ELF: GLIBC_2.34 и GLIBCXX_3.4.30.
На образах с более старыми версиями символов бинарники не загрузятся;
запуск подтверждён на RIG-77 с GLIBC 2.35 и драйвером NVIDIA 550.144.03.
Другие образы HiveOS не проверены.

## Проверка архива без GPU

После распаковки перейдите в единственный каталог `pepew-miner`:

```sh
sha256sum -c SHA256SUMS
./pepepowminer --version
```

Архив содержит проверочные программы в `tests/offline/general` и
`tests/offline/v100`. Их наличие не означает, что GPU-тесты уже выполнены.
Не запускайте GPU-программы на рабочем риге без согласованного окна проверки.

## Подготовленная интеграция HiveOS

Корневые h-manifest.conf, h-config.sh, h-run.sh, h-stats.sh предназначены для
каталога `/hive/miners/custom/pepew-miner`. Вспомогательные программы находятся
в `libexec`; бинарники — в `bin/general` и `bin/v100`.

Конфигурация использует CUSTOM_URL, CUSTOM_TEMPLATE, CUSTOM_PASS и
CUSTOM_USER_CONFIG. Пул и кошелёк должны быть заданы пользователем; реальные
значения в поставку не входят. PEPEW_DEVICES выбирает `all` либо индексы
`nvidia-smi`, например `0,2`. Унаследованный CUDA_VISIBLE_DEVICES оболочка
отклоняет, чтобы не подменять выбор карт. GPU UUID определяются на месте.

Экспертные аргументы разбираются как данные без eval. Параметры пула,
пользователя, пароля и путей диагностики управляются оболочкой. Конфигурация
записывается с правами 0600. Не публикуйте runtime-конфигурацию и логи.

Подготовительный пакет по умолчанию отказывается запускать майнинг.
PEPEW_ALLOW_UNVERIFIED=1 — технический переключатель для заранее разрешённого
испытания, **не разрешение на тест или подключение к пулу**. Для V100 сохраняются
требования эксклюзивного окна, независимого watchdog, дедлайна и восстановления
основного майнера. Эти внешние меры не реализуются простым переключателем.

Оболочка наблюдает за завершением worker/proxy и останавливает свои процессы
при INT/TERM. Это не аппаратный watchdog зависания GPU. Она не меняет драйвер,
частоты, sudo или настройки других майнеров.

Логи: `/var/log/miner/custom/pepew-miner` (PEPEW_LOG_ROOT может переопределить путь).
Состояние процессов — `gpu<N>/` и active-workers.env внутри каталога пакета;
этому каталогу нужны права записи. h-stats учитывает только выбранные карты,
публикует kH/s, PCI bus, температуру, вентилятор и мощность; неизвестные датчики
передаются как null. Совместимость отображения null с целевой HiveOS ещё нужно
проверить на целевом образе.

## Что остаётся перед публичным 1.0

1. Проверить корректность exact binaries на RTX и V100, затем разрешённые pool
   проверки. Для общего RTX-профиля короткая проверка пройдена; для V100 отсутствует.
2. Проверить системные зависимости на поддерживаемом Linux/HiveOS и завершить
   инвентаризацию распространяемых CUDA-компонентов (см. licenses/NOTICE.md).
3. Зафиксировать готовый неизменяемый пакет, контрольные суммы, результаты и
   исходники, затем публиковать стабильный выпуск. Сохранить рабочий путь отката
   до удаления прежних релизов.

Заявления 3–3.5 MH/s на RTX 3080 и исторические измерения V100 не являются
результатами этого пакета. Windows, MMPOS, TLS и failover этим выпуском не
подтверждены. Проектная лицензия находится в LICENSE; лицензии зависимостей —
в licenses/.
