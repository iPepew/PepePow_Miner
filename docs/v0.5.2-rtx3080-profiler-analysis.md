# v0.5.2 RTX 3080 profiler analysis

Validation platform:

- GPU: NVIDIA GeForce RTX 3080 10 GB, Micron GDDR6X
- HiveOS: 0.6-230@260720
- kernel: 6.12.0-hiveos #95
- NVIDIA driver: 610.43.03
- tested miner: v0.5.1-PR, commit 6aff9339157f
- collection interval: 300 seconds

Measured steady state:

- miner hashrate: approximately 1.198 MH/s
- GPU utilization: 100%
- GPU memory utilization: approximately 1%
- SM/graphics clock: 1950 MHz
- memory clock: 9251 MHz
- power: approximately 186 W with a 250 W limit
- P-state: P2
- active clock, thermal and power throttle reasons: none
- miner process: one hot mining thread at approximately 100% of one CPU core
- CUDA or NVIDIA Xid errors: none

The packaged v0.5.1 binary contains the runtime identity `cuda-header80-monolithic-pipeline`, `cudaFuncSetCacheConfig(header80 monolithic)` and only the monolithic host launch error marker. Therefore the v0.5.1 autotuner selected the 64-thread monolithic profile, despite the release name referring to the split pipeline.

## Conclusion

The rig is not limited by PCIe traffic, GPU memory bandwidth, temperature, power limit or driver stability. The bottleneck is the compute instruction path inside the monolithic HooHash kernel.

The hot 64x64 HooHash matrix loop performs repeated exact conversions between small integers and FP64 values, repeated FP64-to-U64 truncation and repeated fraction extraction. Consumer Ampere has intentionally limited FP64 throughput, so these operations are disproportionately expensive.

## v0.5.2 experiment

v0.5.2 adds an autotuned, consensus-preserving alternative that:

1. converts U32 and nibble values to exact FP64 representations with IEEE-754 bit construction;
2. extracts positive FP64 fractional parts with exact bit decomposition;
3. truncates positive FP64 row sums to U64 with exact bit decomposition;
4. converts `hash_mod` once per nonce instead of once per matrix row;
5. returns immediately for a zero nibble because both `sum` and `sw` remain unchanged;
6. compares every optimized profile against the unchanged v0.5.1 monolithic 64-thread baseline;
7. packages only a profile that passes native tests and 4,096 deterministic CPU/CUDA consensus samples.

The 2 MH/s target is not claimed until the RTX 3080 builder and live HiveOS run measure it.
