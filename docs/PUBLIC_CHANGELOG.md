# PepeW Miner 1.0.0

- Первый официальный публичный выпуск нашего майнера для PEPEPOW, Linux/HiveOS.
- Проверенный RTX3080/general бинарник с исправленным fixed-diff1 share target.
- Конфигурация HiveOS, выбор GPU по UUID, статистика и завершение процессов.
- Контрольные суммы и точные исходные SHA; бинарник не пересобран ради номера1.0.
- V100 отложена и не включена; аппаратная поддержка других карт не подтверждена.
