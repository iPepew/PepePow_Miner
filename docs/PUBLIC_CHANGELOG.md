# Изменения к публичной версии 1.0

## 1.0.0-preparation.2 — 16 октября 2026

- Общий и оптимизированный V100 бинарники собраны в единый пакет, с отдельными
  наборами matching offline tests. Байты бинарников сохранены из проверенной
  сборки GitHub Actions 38906725960.
- Добавлен единый вход pepepowminer и адаптеры HiveOS. Выбор по физическому UUID;
  V100 использует свой бинарник и 128 потоков, остальные карты — общий профиль.
- Исправлено завершение монитора, рабочих процессов и proxy; пути статистики
  согласованы с размещением двух бинарников.
- Добавлены проектная лицензия, лицензии BLAKE3/nlohmann-json, инвентаризация
  зависимостей, контрольные суммы, исходные SHA и права файлов.
- CPU-тесты оболочки используют имитаторы. Аппаратная корректность, MH/s,
  принятые shares и совместимость целевой HiveOS ещё не подтверждены.

## План текста стабильного релиза (публиковать после приёмки)

PepeW Miner 1.0 — первый официальный публичный выпуск нашего майнера для
PEPEPOW. В одном пакете объединены общий профиль NVIDIA и отдельный
оптимизированный профиль Tesla V100, интеграция HiveOS и проверочные программы.
Список фактически проверенных карт, требования к системе и результаты тестов
будут указаны для конкретного опубликованного архива.
